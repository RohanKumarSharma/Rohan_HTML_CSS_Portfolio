Project: Personal Portfolio Website
Technologies: HTML5 and CSS3 only.

This responsive personal portfolio introduces Rohan Kumar Sharma, an MCA student and aspiring Full Stack Developer. It includes Home, About, Skills, Projects, Contact, and Footer sections, with working section navigation and links to project/profile pages. CSS Grid and Flexbox are used to arrange content, and responsive media queries adapt the layout to mobile, tablet, and desktop screens. The website uses a consistent dark theme with lime and blue accents, hover/focus states, semantic HTML, and a reduced-motion accessibility preference.
